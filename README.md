# SIGFAM — Sistema Integrado de Gestión FAM

Sistema integral para la administración, liquidación, seguimiento y trazabilidad de expedientes y siniestros del Fondo de Auxilio Mutuo (FAM) - Flota Sugamuxi S.A.

## Características Principales

- **Gestión Multi-Paso de Expedientes:** Registro completo con datos generales, cotizaciones múltiples, deducibles, liquidación a pagar, recobros e información de comités.
- **Liquidación de Siniestros y Aporte del Conductor:** Cálculo dinámico del 10% a cargo del conductor en siniestros y registro de estado de pago (*Pendiente* / *Pagado*).
- **Dashboard Ejecutivo & Analítica:** Indicadores financieros en tiempo real, gráficas de siniestralidad interactiva, análisis por causa raíz y comparativos.
- **Exportación Completa:** Generación de resúmenes oficiales en formato PDF y exportación analítica en Excel (.xlsx).
- **Control de Acceso y Auditoría:** Trazabilidad detallada de cambios por expediente.

## Tecnologías Utilizadas

- **Framework:** Next.js 15 (App Router, React 19)
- **Lenguaje:** TypeScript
- **Estilos y Componentes:** Tailwind CSS, Radix UI, Lucide Icons, Framer Motion
- **Formularios & Validación:** React Hook Form + Zod
- **Gráficos:** Recharts
- **Exportación:** jsPDF, XLSX
